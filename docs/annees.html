Les JT de 20H, année par année beta

Pour chaque année : les grands thèmes des reportages, la part du climat, le pire et le meilleur du traitement climatique — sélection éditoriale issue de l'analyse automatique, chaque exemple vérifié à la main (lien vers la page du JT).

    Méthode : détection par mots-clés sur le titre et le texte des pages web des JT de TF1, France 2 (et France 3 jusqu'en 2023). Les thèmes se recouvrent (un reportage peut compter dans plusieurs) ; les « tops » sont une sélection éditoriale parmi les candidats détectés automatiquement. Les chiffres TF1 2024+ sont sous-estimés (texte collecté plus court) et 2026 est une année partielle. Données & code : github.com/polomarcus/television-news-analyser.
